# Security Policy

Please report vulnerabilities privately through [GitHub's security advisory form](https://github.com/AlexKaiqi/dsh-session-assistant/security/advisories/new). Do not include credentials, private transcripts, or exploitable details in a public issue.

Security fixes target the latest published release. The plugin keeps long-lived Provider credentials on the DSH Host, exposes only bounded Session context, and limits model actions to drafting, explicit Agent submission, ending the voice session, and optional knowledge curation.
